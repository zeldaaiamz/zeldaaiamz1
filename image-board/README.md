# AI 做图看板 (v4)

亚马逊 7 图 Listing 树状做图工作台（GitHub Pages 前端 + ECS `/image-board-api` 后端）。

## 核心规则与能力
1. **第 1 层 · VOC 档案导入 + 白底真修（必做前置）**：
   - 导入真实亚马逊 VOC 报告（痛点 / 痒点 / 惊喜点 / 选择理由 + 秋霜/安然图片规划框）。
   - 上传产品原图（或从已入库图片点选），调用 **豆包 Seedream i2i / Banana (Gemini i2i)** 进行真实白底去背与纯白边缘校准，落盘 `{产品名}/白底图/`。
2. **永久防魔改硬约束**：
   - 所有 AI 出图（主图 / 细节图 / 尺寸图 / 场景图 / 精改支线）**强制绑定已精修白底产品图**作为唯一产品本体（image-to-image reference），严禁无参考图纯文生空想产品，严禁篡改产品外形、结构、颜色、比例或材质。
   - 未选定白底基准图时，前后端双重阻断 `/api/generate`。
3. **落盘规格与目录结构**：
   - 统一分辨率：**`2000 × 2000` 像素**（非正方形按最长边等比缩放至 2000 并居中垫纯白 RGB(255,255,255)）。
   - 统一格式：仅 **`.png` / `.jpg`**（上传 WebP 等格式自动转存为 PNG）。
   - 目录结构（ECS `generated/` 与 Mac `~/Desktop/亚马逊产品图片/` 同构）：
     - `{产品名}/过程图/` — VOC 快照、原图上传、规划框生图、精改版本
     - `{产品名}/白底图/` — 白底真修结果
     - `{产品名}/最终版本/` — 预览框选用 / 定稿图
