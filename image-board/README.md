# AI 做图看板 (v5)

亚马逊 7 图 Listing 树状做图工作台（GitHub Pages 前端 + ECS `/image-board-api` 后端）。

## 核心规则与能力
1. **第 1 层 · VOC 档案导入 + 豆包白底真修（必做前置）**：
   - 导入真实亚马逊 VOC 报告（痛点 / 痒点 / 惊喜点 / 选择理由 + 秋霜/安然图片规划框）。
   - 上传产品原图**默认全选**，点击「开始白底真修」统一使用 **豆包 Seedream** 将所选原图批量去背修成纯白底（存入 `{产品名}/白底图/`）。
   - 白底图支持**单选或多选**并一键批量挂入规划框；点右上角 `×` 触发后端物理删除（含同步队列清理）。
2. **第 2 层 · 图片规划 + 员工对话改词 + 多模型受控图生图**：
   - **永久防魔改硬约束**：所有 AI 出图（豆包 / Banana / Grok / ChatGPT）强制绑定已精修白底产品图作为实物本体（i2i），未选定白底图时前后端双重阻断 `/api/generate`。
   - **多图版本引用（`v1` / `v3` / `v6`）**：在生图提示词中引用 `v3`、`V6`、`v5` 等版本图时，自动解析对应白底图/框内图，按多图参考数组传给豆包 Seedream（自动映射 `图1`/`图2`/`图3` 并禁止把版本号当文字印上画面）。
   - **与负责员工对话改词（`/api/prompt-chat`）**：主图/细节/尺寸直接与**秋霜**对话，场景图与**安然**对话；优化后的提示词自动写回页面并持久化至 `state.boxes[id].promptChat`（聊天仅改词，不自动触发出图）。
   - **Grok 修图/生图**：支持 xAI `grok-imagine-image-2.0`（配置 `XAI_API_KEY` 后自动点亮；未配置时诚实灰显提示未配置）。
   - **全局页内灯箱放大（Lightbox）**：看板内所有缩略图（`cursor: zoom-in`）点击均可页内全屏放大查看，支持滚轮/`+/-`缩放、拖拽平移、`Esc`/点背景/关闭退出及原图下载。
3. **第 3 层 · 预览框 · 亚马逊 7 图定稿（最终版本）**：
   - 支持拖拽调序、页内放大查看、单槽位下载及全部定稿图下载，定稿自动同步至 `{产品名}/最终版本/`（统一 `2000×2000` `.png`/`.jpg`）。
4. **主图策划硬性规范（Hongyan 2026-11-06）**：
   - 唯一权威规范文档：[`/workspace/amazon/specs/amazon_main_image_brief_rules.md`](../../specs/amazon_main_image_brief_rules.md)。
   - 硬性 5 条：① 纯白背景 `RGB(255,255,255)`；② 仅展示在售商品本身、专业实拍、占比 `≥85%`、完整入框不裁切；③ 严禁任何说明性文字、Logo、水印、色块、边框、插图/多角度拼图；④ 一般不要包装盒（除非包装本身是卖点），严禁不在售道具/配件误导；⑤ 尺寸 `≥1600px`（看板统一 `2000×2000`）。
   - `server/lib/voc_map.py` 导入 VOC 与秋霜 `POST /api/prompt-chat` 处理主图时均强制执行该 5 条硬性规范。
