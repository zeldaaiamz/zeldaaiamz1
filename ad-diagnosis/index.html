以上为演示配置，尚未用于真实报表。P = 广告平均每单销售额 × T。

按固定顺序判定

  1. 先核验数据、归因、执行对象及已有观察期。
  2. 零单：点击 ≥ ⌈1.5/C⌉ 且花费 ≥ 1.5P → 降15%；点击 ≥ ⌈3/C⌉ 且花费 ≥ 3P → 停。停投门槛优先。
  3. 至少5单：ACOS ≤ 0.8T → 加候选；≤ 1.1T → 守；≤ 1.3T → 降10%；≤ 1.5T → 降15%；超过 → 降20%。
  4. 1–4单、ACOS > 1.5T 且花费 ≥ 3P → 降10%；其他小样本 → 观察。
  5. 授权核心词、14天至少5单；前后7天各至少5次排名，排名中位数改善 ≥20%且至少3位，ACOS ≤ 1.5T → 保持观察。最多7天或新增花费3P，先到先复核。
  6. 排名例外不覆盖零单止损；缺关键数据、对象冲突 → 待我判。
这是可回测的初始规则，不是亚马逊官方阈值；正式启用前由负责人确认。
